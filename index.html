About Micro-C

Micro-C is a minimalist, multi-target compiler written in Rust for a C-like systems programming language. It is designed for custom operating systems, UEFI applications, and embedded systems.

Supported targets: x86_64 (functional), Windows x64 (semi-functional), ARM64 (in development)
